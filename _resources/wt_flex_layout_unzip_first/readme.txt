I. How to install the WT Flex Layout Module?
- From your admin dashboard click to the "System -> Extensions" menu.
- Click to the "Upload Package Fild" tab.
- Drop and drag or Browse the mod_wt_flex_layout.zip file.

II. Start build layout.
- Create New a module, choose the WT Flex Layout module.
- Click to the "Choose Layout" button.
- Choose a layout, enter content for layout.
- Save, back to front-end view all changes.
